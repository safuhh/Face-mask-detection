Overview

This project is a Face Mask Detection system that can tell whether a person is wearing a mask or not. It uses deep learning with a Convolutional Neural Network (CNN) along with OpenCV for computer vision. The system works on live webcam feeds, images, and videos, detecting multiple faces at the same time.

The main goal is to provide a fast and accurate solution for monitoring mask usage in public spaces, workplaces, or any environment where safety is important. The model can also be retrained on custom datasets, making it flexible and adaptable to different scenarios.

In short, this project combines AI, computer vision, and real-time detection to create a practical, real-world application that’s simple, effective, and easy to use.
